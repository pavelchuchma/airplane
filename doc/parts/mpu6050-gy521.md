# MPU-6050 — 6DOF Gyroscope + Accelerometer (GY-521 style board)

![MPU-6050 module](img/mpu6050-gy521.jpg)

- **Ordered:** (AliExpress, Jan 7, 2026, completed) — diymore Direct Store
- **Product:** [1/5pcs MPU-6050 3 Axis Accelerometer Gyroscope Module 6 DOF](https://www.aliexpress.com/item/1005008584926891.html)
- **Status:** currently wired into the airplane build
- **What it is:** InvenSense MPU-6050 6-axis IMU (3-axis gyro + 3-axis accel + temp sensor) on a GY-521-style breakout with onboard 3.3 V LDO

## Chip specs (InvenSense MPU-6050)

| Parameter | Value |
|---|---|
| Gyroscope | ±250 / ±500 / ±1000 / ±2000 dps, 16-bit (131…16.4 LSB/dps) |
| Accelerometer | ±2 / ±4 / ±8 / ±16 g, 16-bit (16384…2048 LSB/g) |
| Sample rate | gyro up to 8 kHz (DLPF off) / 1 kHz with DLPF; accel 1 kHz |
| Temp sensor | −40…+85 °C, ±1 °C |
| Interface | **I2C only** (up to 400 kHz) — no SPI (that's the MPU-6000) |
| I2C address | **0x68** (AD0 low, board default) / 0x69 (AD0 high) |
| DMP | onboard Digital Motion Processor — 6-axis quaternion fusion, offloads the MCU |
| FIFO | 1024 B buffer; INT pin for data-ready/motion interrupts |
| Aux I2C | XDA/XCL master bus for an external magnetometer (rarely used) |
| Power | chip 2.375–3.46 V; ~3.8 mA full operation; 5 µA sleep |
| WHO_AM_I (reg 0x75) | 0x68 |

## Board (GY-521 style)

- Onboard LDO: **VCC accepts 3.3–5 V**; logic is 3.3 V, onboard I2C pull-ups (fine directly on ESP32)
- 8 pins @ 2.54 mm: VCC, GND, SCL, SDA, XDA, XCL, AD0, INT

| Pin | Function |
|---|---|
| VCC | 3.3–5 V (via LDO) |
| GND | ground |
| SCL / SDA | I2C (to ESP32 GPIO22 / GPIO21) |
| XDA / XCL | aux I2C for external mag — leave unconnected |
| AD0 | address select: low/open = 0x68, high = 0x69 |
| INT | interrupt out (data ready / DMP) — optional, any ESP32 GPIO |

## Wiring to ESP32

```
VCC → 3V3 (or 5V)      SDA → GPIO21
GND → GND              SCL → GPIO22
INT → e.g. GPIO19 (optional, needed for DMP FIFO pacing)
AD0 → open (0x68)
```

⚠️ **Address conflict with GY-91:** the MPU-6050 and the GY-91's MPU-9250 both default to **0x68**. If both are on the same bus, pull one AD0/SAO high to move it to 0x69.

## Libraries

- **Adafruit MPU6050** — simple, clean API (accel/gyro/temp)
- **jrowberg i2cdevlib / MPU6050_6Axis_MotionApps20** — the classic DMP quaternion library (yaw/pitch/roll without external fusion)
- **ElectronicCats/mpu6050** — maintained fork of i2cdevlib for Arduino Library Manager
- Without DMP: run Madgwick/Mahony on raw data — but 6-axis only (no magnetometer) means **yaw drifts** over time

## Gotchas

1. **No magnetometer** — heading (yaw) has no absolute reference and drifts; for a real heading use the GY-91's compass or GPS course
2. **Bias calibration at startup** — average readings on a still, level surface and subtract; DMP users: `CalibrateAccel()/CalibrateGyro()` in i2cdevlib
3. Vibration: on an airplane mount on foam/gel — prop vibration aliases badly into accel data; enable DLPF (e.g. 20–42 Hz)
4. EOL note: MPU-6050 is discontinued by TDK but clones are ubiquitous and generally fine
